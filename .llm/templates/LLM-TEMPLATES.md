# `.llm/templates/`

Human copy-paste **blanks and wrappers** for plan authoring. **Not** abcmemory.

- **Do not** put active or completed plan sets here — use `.llm/plans/active/<name>/` and move to `plans/completed/` when done.
- Copy a template, then create a new folder under `plans/active/` for the real plan content.
- Use for plan autopilot wrappers and similar operator workflows.
- For reusable agent prompt snippets committed as guidance, use `.cursor/prompts/` instead.
- See [LLM.md](/.llm/LLM.md) and [CURSOR-PROMPTS.md](/.cursor/prompts/CURSOR-PROMPTS.md).
