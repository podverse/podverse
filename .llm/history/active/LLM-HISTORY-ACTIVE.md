# `.llm/history/active/`

Optional per-feature session notes while work is in progress. Not required for contributing.

- Create one folder per feature (kebab-case), for example `history/active/my-feature/`.
- Record prompts, decisions, and file lists if your team uses this workflow.
- On merge to `develop`, `.github/workflows/complete-feature.yml` may archive a matching folder to `history/completed/`.
- See [LLM.md](../../LLM.md).
