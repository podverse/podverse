# 05 — Management-web parity (high-level)

## Goal

Ensure management-web coverage grows in parallel with web coverage to avoid blind spots in admin workflows.

## Role/state matrix

1. unauthenticated
2. super-admin
3. restricted/limited admin roles

## Coverage clusters

- login and dashboard
- settings and workers
- users/admins CRUD surfaces
- permissions-based route visibility and access behavior

## Parity principles

- Shared orchestration standards with web suite.
- Deterministic seed personas per role.
- Scoped report runs for role-specific debugging.
