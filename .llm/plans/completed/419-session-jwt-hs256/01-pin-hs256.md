# Session tokens accept only HS256

**Cursor model:** Cursor Grok 4.7 · **Reasoning:** extra high

## Rows

- **R1** Session tokens are signed and checked only as HMAC-SHA256.

## Review before running

No operator question. jsonwebtoken 9.0.2 already rejects the `none` method unless it is
listed. This change makes the method explicit on sign and verify. Tokens this code already
issues keep working.

## Work

- In `signWebSessionToken`, `signMobileTokenPair`, and `verifySessionJwt`, pass
  `algorithms: ['HS256']` on verify and `algorithm: 'HS256'` on sign.
- Do not change expiry, claims, or the cookie.
- Search `jwt.sign` and `jwt.verify` under `apps/` and `packages/`. Any session token
  that uses the shared secret gets the same option. Leave unrelated tokens (if a search
  finds one that is not a session) alone and name them in the final message.
