Playlist owners can add, change, and remove tags when they create or edit a playlist, on the website and on the phone. A playlist can hold a number of tags that defaults to 5, and each name can be a length that defaults to 50 characters. Both limits are set on the API. A new name is stored when the playlist is saved. Typing searches existing names, and Enter or Return adds a chip.

Tags show on playlist rows and on the playlist page, including the phone detail screen. They do not show in the embed player. Public lists can filter by one tag: the website Playlists page when Global is selected, website Browse playlists, and phone Browse playlists. My Playlists, Subscribed, and the phone Library list do not filter by tag. Untagged public playlists stay in the unfiltered list. Private playlists do not show their tags to other people.

The website Playlists page can open on a tag and on the other filters from environment settings. An empty tag is the default. A saved choice and an explicit URL still win. The website and the phone read membership, the tag limits, and the shared instance settings from one public config response. The old public membership GET is gone. Pricing and comparison stay.
