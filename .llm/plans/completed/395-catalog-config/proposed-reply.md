An instance can now set three optional catalog settings. Leaving them unset keeps today's site. The mobile app code is unchanged.

The allowlist is a comma-separated list of Podcast Index ids. Workers add only those feeds, including a show a listed id was merged into. Shows already stored stay.

Turning Music off stops new music from being added and hides artists, albums, tracks, and music livestreams from navigation, chips, and search. Music already stored stays.

Turning Add by RSS off hides that feature. Those pages are not found. The API refuses parses and new follows. Saved rows stay and can be removed.

While the allowlist is set, Podcast Index Add Feed is hidden and refused, and search matches titles of stored shows. With the allowlist unset, search stays the Podcast Index search.
