# Why do some clips start at the wrong time?

Most podcast apps limit clips to less than a minute. {brand_name} lets you create and share clips of
any length, and that flexibility comes with one tradeoff: clips from podcasts that insert dynamic ads
can drift out of sync.

Dynamic ads are advertisements rotated into the same episode, so each listener hears a different set
of them. Because they change the overall length of the episode, the timestamps of a clip made from
that episode do not stay accurate.

Full support for podcasts with dynamic ads is possible, and we would like to add it, but for fair use
reasons it requires permission from each podcaster.
