# ¿Por qué algunos clips empiezan en el momento equivocado?

La mayoría de las apps de podcasts limitan los clips a menos de un minuto. {brand_name} te permite
crear y compartir clips de cualquier duración, y esa flexibilidad tiene una contrapartida: los clips
de podcasts que insertan anuncios dinámicos pueden desincronizarse.

Los anuncios dinámicos son anuncios que se rotan dentro del mismo episodio, por lo que cada oyente
escucha un conjunto distinto. Como cambian la duración total del episodio, las marcas de tiempo de un
clip hecho a partir de ese episodio dejan de ser precisas.

El soporte completo para podcasts con anuncios dinámicos es posible, y nos gustaría añadirlo, pero
por razones de uso justo requiere permiso de cada podcaster.
