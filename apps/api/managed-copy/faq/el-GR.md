# Γιατί κάποια clips ξεκινούν σε λάθος χρόνο;

Οι περισσότερες εφαρμογές podcast περιορίζουν τα clips σε λιγότερο από ένα λεπτό. Το {brand_name}
σάς επιτρέπει να δημιουργείτε και να μοιράζεστε clips οποιασδήποτε διάρκειας, και αυτή η ευελιξία
φέρνει έναν συμβιβασμό: τα clips από podcasts που εισάγουν δυναμικές διαφημίσεις μπορεί να βγαίνουν
εκτός συγχρονισμού.

Οι δυναμικές διαφημίσεις είναι διαφημίσεις που εναλλάσσονται μέσα στο ίδιο επεισόδιο, οπότε κάθε
ακροατής ακούει διαφορετικό σύνολο. Επειδή αλλάζουν τη συνολική διάρκεια του επεισοδίου, οι χρονικές
σημάνσεις ενός clip που δημιουργήθηκε από αυτό το επεισόδιο δεν παραμένουν ακριβείς.

Η πλήρης υποστήριξη για podcasts με δυναμικές διαφημίσεις είναι εφικτή και θα θέλαμε να την
προσθέσουμε, αλλά για λόγους θεμιτής χρήσης απαιτεί άδεια από κάθε podcaster.
