# Δημιουργία clip

- Πατήστε "Ώρα έναρξης" και "Ώρα λήξης" για να οριστούν στον τρέχοντα χρόνο αναπαραγωγής.
- Η ώρα λήξης είναι προαιρετική. Ένα clip χωρίς ώρα λήξης παίζει μέχρι το τέλος του επεισοδίου.
- Χρησιμοποιήστε το κουμπί αναπαραγωγής σε οποιαδήποτε από τις δύο ώρες για να το ακούσετε πριν το
  αποθηκεύσετε.
- Η ονομασία ενός clip το κάνει πιο εύκολο να το βρείτε αργότερα.
- Η ώρα έναρξης διαφέρει στα clips από podcasts που εισάγουν δυναμικές διαφημίσεις.
