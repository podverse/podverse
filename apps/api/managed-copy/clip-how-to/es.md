# Cómo hacer un clip

- Toca "Hora de inicio" y "Hora de fin" para ajustarlas al tiempo de reproducción actual.
- La hora de fin es opcional. Un clip sin hora de fin se reproduce hasta el final del episodio.
- Usa el botón de reproducir de cualquiera de las dos horas para escucharlo antes de guardarlo.
- Ponerle un nombre a un clip hace que sea más fácil encontrarlo después.
- La hora de inicio varía en clips de podcasts que insertan anuncios dinámicos.
