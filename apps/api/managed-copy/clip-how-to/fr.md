# Créer un clip

- Appuyez sur "Heure de début" et "Heure de fin" pour les régler sur le temps de lecture actuel.
- L'heure de fin est facultative. Un clip sans heure de fin se lit jusqu'à la fin de l'épisode.
- Utilisez le bouton lecture de l'une ou l'autre heure pour l'écouter avant de l'enregistrer.
- Donner un titre à un clip le rend plus facile à retrouver plus tard.
- L'heure de début varie pour les clips issus de podcasts qui insèrent des publicités dynamiques.
