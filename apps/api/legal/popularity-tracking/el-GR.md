# Τι είναι η παρακολούθηση δημοτικότητας

Οι κατατάξεις μοναδικών ακροατών βοηθούν τους ανθρώπους να ανακαλύπτουν δημοφιλείς εκπομπές και βοηθούν τους δημιουργούς να κατανοούν πότε το έργο τους φτάνει σε κοινό.

# Τι καταγράφει το {brand_name} αν πείτε ναι

Αν πείτε ναι, το {brand_name} καταγράφει ένα ψευδώνυμο γεγονός ακρόασης όταν αναπαράγετε επεισόδια του καταλόγου. Το γεγονός χρησιμοποιεί ένα εσωτερικό αναγνωριστικό λογαριασμού. Δεν εμφανίζεται ως το δημόσιο προφίλ σας ούτε ως το όνομα χρήστη σας.

# Πώς χρησιμοποιούνται τα δεδομένα

Αυτά τα γεγονότα τροφοδοτούν τις κατατάξεις μοναδικών ακροατών και τις λίστες τάσεων ώστε οι ακροατές να βρίσκουν εκπομπές που απολαμβάνει ο κόσμος και οι δημιουργοί να βλέπουν πότε το έργο τους φτάνει σε κόσμο.

# Τι δεν κάνουμε

- Τα γεγονότα αποθηκεύονται στους διακομιστές μας.
- Δεν πουλάμε ποτέ αυτά τα δεδομένα.
- Δεν τα χρησιμοποιούμε για να σας δείχνουμε διαφημίσεις.
