# Mobile store metadata as code

This directory tracks next-gen mobile store assets for `com.podverse.app.next`.

## Scope

- Store listing copy drafts (release notes, descriptions)
- Screenshot inventories and source references
- Asset manifests used by operator release workflows

## Safety

- Do not publish or sync these assets to existing production Podverse listings.
- Keep next-gen metadata isolated until convergence decision step 4.25.

## Notes

- EAS profile naming is defined in `apps/mobile/eas.json` (`internal`, `beta`, `production`).
- Keep this directory free of secrets and private credentials.
