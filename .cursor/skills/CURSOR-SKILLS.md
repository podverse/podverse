# `.cursor/skills/`

Task- and domain-specific agent workflows. One skill folder per topic; each folder contains a `SKILL.md` with YAML frontmatter.

- Add or edit skills when agents need repeatable patterns (API, E2E, K8s, and so on).
- Skill `name` in frontmatter must match the folder name.
- See **llm-cursor-source** and [DOCS-DEVELOPMENT-LLM.md](../../docs/development/llm/DOCS-DEVELOPMENT-LLM.md).
