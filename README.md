# Podverse

Open source podcast app with Podcasting 2.0 support.

## Quick Start
```bash
nvm use && npm install
npm run build:packages
npm run dev:api    # localhost:3000
npm run dev:web    # localhost:3001
```

## Structure
- `packages/` - Shared packages
- `apps/` - Applications
- `docs/` - Documentation
