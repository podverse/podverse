# Fake Data Generator - Lookup Tables

## Overview

Lookup tables contain a finite set of predefined rows that should **NOT** be generated by the faker. These tables are typically populated during database migrations and contain static reference data used by other entities.

The fake data generator must reference these existing rows by their IDs rather than creating new entries.

## Lookup Table Utility Module

Create a utility module to centralize lookup table access:

## Validation

The generator should validate that lookup tables exist before generating data:

```typescript
// src/faker/utils/validation.ts

import { DataSource } from 'typeorm';

export async function validateLookupTables(dataSource: DataSource): Promise<void> {
  const requiredTables = [
    { name: 'sharable_status', minRows: 3 },
    { name: 'account_membership', minRows: 2 },
    { name: 'feed_flag_status', minRows: 6 },
    { name: 'item_flag_status', minRows: 4 },
    { name: 'live_item_status', minRows: 3 },
    { name: 'channel_itunes_type', minRows: 2 },
    { name: 'item_itunes_episode_type', minRows: 3 },
    { name: 'medium', minRows: 29 },
    { name: 'category', minRows: 100 }
  ];

  for (const table of requiredTables) {
    const result = await dataSource.query(
      `SELECT COUNT(*) as count FROM ${table.name}`
    );
    const count = parseInt(result[0].count, 10);
    
    if (count < table.minRows) {
      throw new Error(
        `Lookup table '${table.name}' has ${count} rows, expected at least ${table.minRows}. ` +
        `Please run database migrations first.`
      );
    }
  }
  
  console.log('✓ All lookup tables validated');
}
```
