# Archived release notes (generated)

This directory is populated by automation after a successful publish (GitHub Actions) from `alpha`, `beta`, or `main`.

Each `RELEASE-*.md` is a snapshot of [CHANGELOG-UPCOMING](CHANGELOG-UPCOMING.md) and metadata from the run that built the version.

**Do not delete** these files to fix a mistake in an upcoming entry; add a follow-up line in [CHANGELOG-UPCOMING](CHANGELOG-UPCOMING.md) on `develop` instead.

This path follows the monorepo documentation convention: one descriptive doc per area under `docs/`.
